الملخص المهني

خريج علوم الحاسوب من جامعة كربلاء، أتمتع بخبرة عملية في تطوير البرمجيات باستخدام لغات مثل C, C++, C#, Python, PHP, JavaScript، مع إتقان لقواعد البيانات (SQL Server, MySQL, SQLite) وأدوات التحكم بالإصدارات مثل Git. عملت على مشاريع متنوعة تشمل تطبيقات سطح المكتب والويب مثل الأرشفة الذكية و محاكي الرحلات الجوية. أسعى لتطوير خبرتي في مجالات البرمجة التنافسية، الذكاء الاصطناعي، والمساهمة في المشاريع مفتوحة المصدر.

  • تطبيق الأرشفة الذكية
    PHP, Laravel, MySQL, HTML, CSS, JavaScript
    تطوير نظام لأرشفة المستندات إلكترونيًا يهدف إلى تخزين، فهرسة واسترجاع المستندات بكفاءة.
  • محاكي الرحلات الجوية
    C#, Windows Forms, Gmap
    تصميم وتطوير برنامج يحاكي الرحلات الجوية لأغراض تدريبية وتحليل بيانات مسجلة.
  • برنامج الحوافز
    C#, Windows Forms, SQL Server
    بناء نظام لإدارة الحوافز والمكافآت للموظفين مع تقارير ومتابعة الأداء.
  • تطبيقات ويب صغيرة
    PHP, Laravel, Vue.js, MySQL
    تطوير مواقع وتطبيقات ويب بمزايا مختلفة لأغراض تجريبية ومشاريع عملاء صغار.
