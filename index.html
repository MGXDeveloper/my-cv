الملخص المهني

خريج علوم الحاسوب من جامعة كربلاء، أتمتع بخبرة عملية قوية في تطوير تطبيقات الويب وسطح المكتب Full-Stack. متخصص في بناء الأنظمة الخلفية (Backend) السحابية والمستقرة باستخدام تقنيات .NET (ASP.NET Core, Web API, MVC) والتحكم بقواعد البيانات المتقدمة مثل SQL Server، بالإضافة إلى خبرة إضافية في PHP (Laravel) وPython. أمتلك شغفاً بالبرمجة التنافسية، هندسة البرمجيات النظيفة، وحماية البيانات الرقمية.

المشاريع الرئيسية

  • نظام إدارة المهام والمستخدمين (RESTful API Project)
    C#, ASP.NET Core, Web API, Entity Framework Core (EF Core), SQL Server
    تطوير واجهة برمجية (Backend API) متكاملة تتبع معايير REST Architecture. تم بناء نظام الصلاحيات والمصادقة الآمنة بالاعتماد على Identity System & JWT Tokens، وتوظيف نمط الـ DTOs (Data Transfer Objects) لتأمين البيانات المتبادلة وتحسين الأداء وربط النظام بقاعدة بيانات SQL Server.
  • تطبيق الأرشفة الذكية
    PHP, Laravel, MySQL, HTML, CSS, JavaScript
    تطوير نظام لأرشفة المستندات إلكترونيًا يهدف إلى تخزين، فهرسة واسترجاع المستندات بكفاءة.
  • محاكي الرحلات الجوية
    C#, Windows Forms, Gmap
    تصميم وتطوير برنامج يحاكي الرحلات الجوية لأغراض تدريبية وتحليل بيانات مسجلة.
  • برنامج الحوافز والمكافآت
    C#, Windows Forms, SQL Server
    بناء نظام لإدارة الحوافز والمكافآت للموظفين مع تقارير ومتابعة الأداء.
